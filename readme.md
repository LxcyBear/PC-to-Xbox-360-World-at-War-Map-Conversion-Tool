# PC2XB3
The World at War PC to Xbox 360 Map Conversion Tool

This tool allows users to convert PC World at War custom user created zombies maps and convert them to use on modified Xbox 360 consoles with use on either the CodXe or Wonderland modification modules.

(10-23-2026) This tool is nearing ~85% completion. First beta release should be this weekend or early-mid next week.
